# kitapsepeti_project_cypress (Cypress E2E Test Automation – E-Commerce Project)

This repository contains **end-to-end (E2E) test automation scenarios** written with **Cypress** for an e-commerce web application.
The project focuses on **real user flows** such as product search, cart operations, and guest checkout.

---

## 🔧 Technologies & Tools
- Cypress
- JavaScript
- Page Object Model (POM)
- Git & GitHub
- Node.js

---

Test Design Notes:

Page Object Model (POM) is used to improve test readability and maintainability.
Locators are separated from test logic.
Scenarios are written based on manual test cases and real user behavior.
Assertions are added to validate critical user actions and system responses.


Purpose of This Project!!

QA automation practice, 
 Improving Cypress & POM skills,
 Demonstrating E2E testing knowledge in technical interviews
